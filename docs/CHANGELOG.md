### التغييرات الرئيسية

#### ✅ نظام تحميل ديناميكي
- تم إنشاء `src/utils/artistLoader.js` لتحميل معلومات الفنانين تلقائياً
- يتم قراءة البيانات من ملفات MD بدلاً من كود JavaScript ثابت
- دعم تحميل الصور تلقائياً من مجلدات الفنانين

#### ✅ بنية مجلدات جديدة
```
public/artists/
├── [اسم_الفنان]/
│   ├── avatar.jpg      (الصورة الشخصية)
│   ├── work_1.png      (صور الأعمال)
│   ├── work_2.png
│   └── info.md         (معلومات الفنان)
```

#### ✅ ملفات MD للمحتوى
- كل فنان له ملف `info.md` يحتوي على:
  - الاسم (عربي/إنجليزي)
  - التخصص (عربي/إنجليزي)
  - السيرة الذاتية (عربي/إنجليزي)
  - شروط التعاون (عربي/إنجليزي)
  - روابط التواصل الاجتماعي

#### ✅ تحسينات الكود
- تم تبسيط `src/data/artists.js` ليحتوي فقط على الترجمات
- تم حذف ملفات البيانات الثابتة (`khaled.js`, `alaa.js`)
- تم تحديث `src/main.js` لاستخدام النظام الديناميكي
- إضافة شاشة تحميل أثناء جلب بيانات الفنانين

#### ✅ دعم Base Path
- تم تحديث المسارات لتعمل مع `base: '/rendergroup/'` في vite.config
- استخدام `import.meta.env.BASE_URL` للمسارات الديناميكية

### الملفات الجديدة

1. **src/utils/artistLoader.js** - نظام التحميل الديناميكي

4. **QUICK_START.md** - دليل البدء السريع
5. **README_AR.md** - ملف README بالعربية

### كيفية الترقية

إذا كان لديك نسخة قديمة من المشروع:

1. انقل صور الفنانين إلى `public/artists/[اسم_الفنان]/`
2. أنشئ ملف `info.md` لكل فنان
3. حدّث `src/utils/artistLoader.js` بأسماء المجلدات
4. احذف الملفات القديمة من `src/data/artists/`
